# e-Filing กรมสรรพากร — คัดเอกสารภาษีออนไลน์

## กฎสำคัญ (ต้องทำตามเสมอ)

### 1. ทวนคำสั่งก่อนดำเนินการทุกครั้ง

เมื่อได้รับคำสั่งคัดเอกสาร ต้อง **สรุปทวนกลับผู้สั่งงาน** ก่อนเริ่มทำ:
- บริษัทอะไร (LYNX / LHD / อื่นๆ)
- ประเภทแบบอะไร (ภ.พ.30, ภ.ง.ด.53, ฯลฯ)
- ช่วงเวลา (เดือน/ปีอะไรบ้าง)
- รอ confirm จากผู้สั่งก่อน → ค่อยเริ่มทำ

### 2. ดาวน์โหลดทั้งภาพแบบ + ใบเสร็จเสมอ

ถ้าในระบบมีทั้ง "ภาพแบบ" และ "ภาพใบเสร็จรับเงิน/ใบรับ" → ดาวน์โหลดมาทั้งคู่โดยไม่ต้องรอสั่ง

### 3. เอกสารเยอะ → ส่ง Drive link

ถ้ามีไฟล์มากกว่า 3 ไฟล์ → อัปโหลดเข้า Google Drive แล้วส่งลิงก์เดียว (ไม่ส่งไฟล์ทีละตัวในกลุ่ม)
- สร้าง folder ใน "งานที่ทำแล้ว (Completed Work)" — ID: `1J6NNI3WrkrKERF6p_D1G5_jhQqLKI9hC`
- ตั้งชื่อ folder: `<ประเภทแบบ> <บริษัท> — <ช่วงเวลา>` เช่น `ภ.พ.30 LYNX — ก.ย.68 ถึง ก.พ.69`
- เปิดสิทธิ์ให้คุณต่าย + คุณแก้ว + คนสั่งงาน อัตโนมัติ

### 4. คัดเฉพาะเดือนที่ยื่นสำเร็จ

- สถานะต้องเป็น "ยื่นแบบสำเร็จ (ออกใบเสร็จรับเงินแล้ว)" เท่านั้น

- แจ้งผู้สั่งว่าเดือนไหนยังไม่มี

## ขั้นตอนการคัดเอกสาร

### Step 1: Login
1. เปิด https://efiling.rd.go.th/rd-efiling-web/login
2. กรอก เลขประจำตัวผู้เสียภาษีอากร + รหัสผ่าน
3. กด "เข้าสู่ระบบ"

### Step 2: ค้นหาแบบ
1. ไปที่ "ตรวจสอบผลการยื่นแบบ" (tab ภาษีอื่นๆ จากการประกอบกิจการ)
2. ค้นหาได้ 2 วิธี:
   - **ค้นหาจากหมายเลขอ้างอิง** → พิมพ์ในช่อง search แล้ว submit
   - **ค้นหาขั้นสูง** → เลือกประเภทแบบ + ปีภาษี + เดือนภาษี → กดค้นหา

### Step 3: ดาวน์โหลด
1. กดปุ่มจุด 3 จุด (⋮) ในคอลัมน์สุดท้ายของแถว → เมนู "จัดการแบบ"
2. กด "พิมพ์ภาพแบบ/ภาพใบเสร็จ"
3. จะเปิด dialog "เลือกรายการ" มี 2 แถว:
   - **ภาพแบบ** → กดดาวน์โหลด (เปิด tab ใหม่เป็น PDF)
   - **ภาพใบเสร็จรับเงิน/ใบรับ** → กดดาวน์โหลด (เปิด tab ใหม่เป็น PDF)
4. ใช้ CDP ดึง cookies จาก main tab → download PDF จาก URL ของ tab ใหม่
5. ปิด PDF tab + ปิด dialog

### Step 4: ทำซ้ำ
- ล้างช่อง search → พิมพ์ ref ถัดไป → ทำ Step 3 ซ้ำ

### Step 5: เปลี่ยนบริษัท (ถ้าต้องการ)
- กดชื่อบริษัทมุมขวาบน → กด "ออกจากระบบ"
- Login ใหม่ด้วย user ของอีกบริษัท

## หมายเหตุทางเทคนิค

### ระบบกำลังสร้างไฟล์
- บางเดือนเมื่อกด "พิมพ์ภาพแบบ/ภาพใบเสร็จ" จะขึ้น dialog "ระบบกำลังดำเนินการสร้างภาพแบบ และภาพใบเสร็จ/ใบรับ"
- วิธีแก้: กดปิด → รอ 5-10 วินาที → กดจุด 3 จุดแล้วกด "พิมพ์ภาพแบบ/ภาพใบเสร็จ" ใหม่

### Download ผ่าน CDP
- กดดาวน์โหลดจะเปิด tab ใหม่ที่มี URL ของ PDF
- ใช้ CDP `Network.getCookies` จาก main tab → แล้ว `urllib.request` download ด้วย cookies
- ปิด tab PDF ด้วย CDP `Page.close`

### Session หมดอายุ
- Session หมดอายุเร็ว ถ้า idle นาน → ต้อง login ใหม่
- เมื่อเปลี่ยนบริษัท ต้อง logout + login ใหม่เสมอ
