# Standard Agreement Form — มาตรฐานสัญญา/ข้อตกลงในนามบริษัท

## เมื่อไหร่ใช้ Skill นี้
- ร่างสัญญา ข้อตกลง หนังสือมอบอำนาจ ที่ออกในนามบริษัท
- เอกสารที่มีบริษัทใน vault เป็นคู่สัญญา (รองรับหลายบริษัท)
- เอกสารที่ต้องลงนามโดยกรรมการบริษัท
- **หากบริษัทที่ระบุไม่อยู่ใน vault** → สอบถามข้อมูลบริษัทให้ครบก่อนลงมือ (ชื่อเต็ม, ที่อยู่, กรรมการผู้มีอำนาจ, เลขทะเบียน ฯลฯ)

## ใช้ร่วมกับ
- **agreement-format** — สำหรับ format/layout ของเอกสาร
- **doc-vault** — สำหรับดึงข้อมูลบริษัทและบุคคล

## 1. การใช้คำเป็นทางการ

### หลักการ
- ใช้ภาษาทางการ ราชการ ตลอดทั้งเอกสาร
- ไม่ใช้ภาษาพูด คำย่อ หรือคำสแลง

### คำที่ต้องใช้

| ❌ ห้ามใช้ | ✅ ใช้แทน |
|-----------|----------|
| ทำผิด | ฝ่าฝืน / กระทำการอันมิชอบ |
| ไล่ออก | เลิกจ้าง |
| ลงโทษ | ดำเนินการทางวินัย |
| เงินเดือน | ค่าจ้าง / ค่าตอบแทน |
| ตกลงกัน | คู่สัญญาทั้งสองฝ่ายตกลงร่วมกัน |
| ให้...ทำ | มีหน้าที่ / พึงปฏิบัติ |
| ไม่ให้ทำ | ห้ามมิให้ |
| บอกให้รู้ | แจ้งให้ทราบ |
| แก้ไข | ดำเนินการแก้ไข |
| ทันที | โดยพลัน / โดยทันที |
| เจ้านาย | ผู้บริหาร / หัวหน้างาน |
| ของบริษัท | ของบริษัทฯ |

### โครงสร้างประโยค
- ใช้ประโยค passive voice เมื่อเหมาะสม: "ให้ถือว่า..." แทน "เราจะถือว่า..."
- อ้างอิงคู่สัญญาด้วยคำที่นิยามไว้: "บริษัท" / "พนักงาน" / "ผู้เช่า" ฯลฯ
- ไม่ใช้ชื่อเล่น/ชื่อย่อในเนื้อหาเอกสาร
- ระบุเงื่อนไขให้ชัดเจน: "ภายใน X วัน" ไม่ใช่ "โดยเร็ว"

## 2. ตำแหน่งตัวแทนบริษัท

### ก่อนร่างเอกสาร — ต้องตรวจ vault ทุกครั้ง
```
vault.json → companies → ชื่อบริษัทที่ระบุ → ข้อมูลบริษัท
vault.json → persons → ชื่อผู้ลงนาม → role, title, position, company
```
**หากบริษัทไม่อยู่ใน vault** → สอบถามข้อมูลให้ครบก่อน: ชื่อเต็มบริษัท, ที่อยู่จดทะเบียน, กรรมการผู้มีอำนาจลงนาม, เลขทะเบียนนิติบุคคล

### ข้อมูลที่ต้องระบุให้ครบ

#### ส่วนคู่สัญญา (preamble)
1. ชื่อเต็มบริษัท (จาก vault → companies → ชื่อบริษัทที่ระบุ หรือจากข้อมูลที่สอบถามมา)
2. ที่อยู่สำนักงานจดทะเบียน (ตรวจจาก vault → companies → cert)
3. ชื่อ-นามสกุลผู้ลงนาม + คำนำหน้า (จาก vault: title + ชื่อ)
4. ตำแหน่ง: "กรรมการผู้มีอำนาจลงนาม"

#### ส่วนลงนาม (signature)
1. label: ใช้ตำแหน่งตามจริง เช่น "กรรมการ" (ไม่ใช่ "ผู้แทนบริษัท")
2. ชื่อ-นามสกุลในวงเล็บ
3. ชื่อบริษัทใต้ชื่อ

#### ห้ามทำเด็ดขาด
- ❌ แปลชื่อ-นามสกุลจาก Telegram metadata
- ❌ เดาตำแหน่ง/คำนำหน้า
- ❌ ใช้ข้อมูลจาก memory โดยไม่ cross-check กับ vault

## 3. ตรวจสอบเนื้อหา — ความเป็นธรรม

### หลักการสำคัญ
> **"ไม่เอาเปรียบคู่สัญญา แต่ไม่ยอมเสียเปรียบในสิทธิ์ที่มี"**

### Checklist ตรวจสอบก่อนนำเสนอ

#### ✅ สิทธิ์ของบริษัทที่ต้องมี
- [ ] สิทธิ์ยกเลิก/เพิกถอนได้ทุกเมื่อ โดยไม่ต้องแจ้งเหตุผล
- [ ] สิทธิ์เรียกร้องค่าเสียหาย ทั้งทางแพ่งและอาญา
- [ ] สิทธิ์หักค่าเสียหายจากค่าจ้าง/เงินค้ำประกัน (ถ้ามี)
- [ ] สิทธิ์แก้ไขข้อตกลงเป็นลายลักษณ์อักษร
- [ ] กำหนดบทลงโทษชัดเจน — เลิกจ้างโดยไม่จ่ายชดเชย (กรณีทุจริต)

#### ✅ หน้าที่ของคู่สัญญาอีกฝ่ายที่ต้องระบุ
- [ ] หน้าที่รายงาน/ส่งเอกสาร — กำหนดระยะเวลาชัด (เช่น "ภายใน 3 วัน")
- [ ] หน้าที่รักษาความลับ
- [ ] หน้าที่คืนทรัพย์สิน — กำหนดระยะเวลา (เช่น "ภายใน 3 วันทำการ")
- [ ] หน้าที่แจ้งเหตุผิดปกติทันที
- [ ] ยินยอมรับเงื่อนไขทุกข้อ

#### ❌ สิ่งที่ต้องระวัง — อย่าให้เสียเปรียบ
- [ ] ไม่มีข้อที่ให้อีกฝ่ายยกเลิกฝ่ายเดียวได้ (ถ้าไม่จำเป็น)
- [ ] ไม่มีข้อยกเว้นความรับผิดที่กว้างเกินไป
- [ ] ไม่มีช่องว่างให้ตีความได้หลายแบบ — ใช้คำชัดเจน
- [ ] กำหนดระยะเวลาทุกข้อ — ไม่ปล่อยให้เป็น "ตามสมควร"

#### ⚖️ ไม่เอาเปรียบคู่สัญญา
- [ ] ไม่หักค่าจ้างเกินกว่าค่าเสียหายจริง
- [ ] ให้โอกาสชี้แจงก่อนลงโทษ (ถ้าเหมาะสม)
- [ ] ข้อตกลงชัดเจน ทั้งสองฝ่ายเข้าใจตรงกัน
- [ ] ไม่มีเงื่อนไขซ่อน หรือข้อผูกมัดที่ไม่สมเหตุสมผล

## 4. ตรวจสอบเอกสารจดทะเบียนบริษัทจาก Vault

### ก่อนร่างเอกสารทุกครั้ง ต้องตรวจ vault
```
vault.json → companies → ชื่อบริษัทที่เป็นคู่สัญญา
```
**หากบริษัทไม่อยู่ใน vault** → สอบถามข้อมูลให้ครบก่อนลงมือ

### ข้อมูลที่ต้องตรวจ
1. **หนังสือรับรองบริษัท (cert)** — ตรวจวันที่ออก + อายุ
2. **ทะเบียนภาษี (vat_reg)** — เลขประจำตัวผู้เสียภาษี
3. **รายชื่อกรรมการ** — ตรวจว่าผู้ลงนามเป็นกรรมการจริง
4. **อำนาจลงนาม** — ตรวจว่ากรรมการคนนี้ลงนามผูกพันบริษัทได้ (ดู role ใน vault)

### ข้อมูลบุคคลจาก Vault
```
vault.json → persons → ชื่อ → title, role, company, position
```

ตรวจสอบ:
- คำนำหน้า (title): นาย/นาง/นางสาว
- ตำแหน่ง (role): กรรมการ ลงลายมือชื่อ+ประทับตราผูกพันบริษัทได้?
- บริษัท (company): ตรงกับบริษัทที่เป็นคู่สัญญา?

## ข้อสำคัญเพิ่มเติม

### ข้อที่ควรมีในทุกสัญญา/ข้อตกลง
1. **ผลบังคับใช้** — "มีผลตั้งแต่วันที่ลงนาม"
2. **การแก้ไขเปลี่ยนแปลง** — "ต้องทำเป็นลายลักษณ์อักษร ลงนามทั้งสองฝ่าย"
3. **การรับทราบ** — "อ่านและเข้าใจครบถ้วน ยินยอมปฏิบัติตาม"
4. **จำนวนฉบับ** — "ทำขึ้นเป็นสองฉบับ เก็บรักษาฝ่ายละหนึ่งฉบับ"

### Flow การทำงาน
1. อ่าน skill นี้ + agreement-form
2. **ถามผู้สั่งงานว่าสัญญาออกในนามบริษัทไหน** (ถ้ายังไม่ระบุ)
3. ตรวจ vault — ค้นหาบริษัทที่ระบุ
   - **พบใน vault** → ดึงข้อมูลบริษัท + บุคคลที่เกี่ยวข้อง
   - **ไม่พบใน vault** → สอบถามข้อมูลให้ครบ: ชื่อเต็มบริษัท, ที่อยู่จดทะเบียน, กรรมการผู้มีอำนาจ, เลขทะเบียน ฯลฯ
4. ร่างเนื้อหา — ใช้คำทางการ
5. ตรวจ checklist ความเป็นธรรม
6. สรุปให้ผู้สั่งงาน confirm ก่อนสร้างเอกสาร
7. สร้างเอกสารตาม agreement-format
8. Self-test ตาม checklist ก่อนนำเสนอ
